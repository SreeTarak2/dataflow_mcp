DESCRIPTION RULES (STRICT)
==================================================
- 120–300 characters
- 1–3 sentences
- Neutral, informational tone
- No hype, no dates, no eligibility restatement

MANDATORY STRUCTURE — follow this order:
Sentence 1: What to submit
  Start with the submission type and any hard format constraint.
  "Submit short films under 40 minutes across any genre."
  "Submit original paintings, sculptures, or mixed media works."
  "Propose a climate-tech startup addressing food security."

Sentence 2: Who it is for
  State the audience plainly. Mirror eligibilityLabel tone.
  "Open to filmmakers worldwide."
  "For individual artists aged 18 and above."
  "For early-stage startups from African countries."

Sentence 3 (optional but preferred): One distinctive signal
  The single most useful thing that makes this contest worth
  applying to over others in the same category.
  NOT the prize amount — that has its own field.
  NOT the deadline — that has its own field.
  "Oscar-qualifying with jury selection across three categories."
  "Fully funded — covers tuition, stipend, and travel."
  "Winning works exhibited at a major international venue."

BANNED PATTERNS (never output these):
- Never start with the organizer name
- Never start with "Organized by"
- Never start with "The [Organizer] invites"
- Never describe organizer history or prestige
- Never repeat the prize amount
- Never repeat the deadline
- Never repeat the location
- Never use: premier, prestigious, renowned, leading,
             world-class, unique opportunity, major platform

SELF-CHECK before outputting description:
1. Does sentence 1 tell the user what to submit? If not — rewrite.
2. Does sentence 2 tell the user who this is for? If not — rewrite.
3. Does any sentence mention organizer name, prestige, or history?
   If yes — delete that sentence entirely.

PRIZE RULES (EVIDENCE-BASED)
==================================================
prizeSummary (REQUIRED when isMonetary = true):
- 2–10 words, human-readable string
- Card renders this directly — no conditional logic on amounts
- If exact amount is known:   "Cash prizes totaling €20,000"
- If amount is mentioned but unclear: "Cash prizes awarded"
- If non-monetary only: "Certificate + exhibition rights"
- If mixed: "Cash prizes + residency"
- NEVER leave null when isMonetary = true

originalAmount:
- TYPE IS STRING — not a number
- Capture exactly as written in source: "€20,000", "NGN 5,000,000", "$10k+"
- Do not convert — conversion is handled separately in totalUSD
- If no amount found: null

totalUSD:
- Number — USD equivalent of originalAmount
- Set to null (NOT 0) when conversion fails or amount is ambiguous
- 0 is a valid value ONLY when prize is explicitly stated as zero value
- NEVER default to 0

currency:
- ISO code: "USD", "EUR", "INR", "NGN" etc.
- null if not stated — do not default to "USD"

Classification:
1. Explicit amount → isMonetary = true, fill originalAmount + totalUSD + prizeSummary
2. Monetary mentioned, no amount → isMonetary = true, originalAmount = null,
   totalUSD = null, prizeSummary = "Cash prizes awarded"
3. Only non-monetary → isMonetary = false, both amounts = null,
   prizeSummary = [describe what is awarded]
4. No prize info → isMonetary = null, both amounts = null, prizeSummary = null

NEVER infer money.

ENTRY FEE RULES (FOUR STATES — STRICT)
==================================================
Pick EXACTLY ONE state. Never default fee.amount to 0.

STATE 1 — Confirmed free:
  Source explicitly says "free", "no entry fee", "free to enter",
  or "no registration fee"
  → isFree: true
  → fee.amount: 0
  → fee.currency: null
  → feeConfidence: "confirmed"
  → feeNote: null

STATE 2 — Confirmed paid, amount known:
  Source states a specific fee amount
  → isFree: false
  → fee.amount: [extracted number]
  → fee.currency: [ISO code]
  → feeConfidence: "extracted"
  → feeNote: null (or tier description if fee varies)

STATE 3 — Confirmed paid, amount unknown:
  Source mentions a fee exists but no amount is stated,
  OR fee varies by category with no extractable base amount
  → isFree: false
  → fee.amount: null
  → fee.currency: null
  → feeConfidence: "unknown"
  → feeNote: null

STATE 4 — Fee status unclear:
  Source does not mention fees at all
  → isFree: null
  → fee.amount: null
  → fee.currency: null
  → feeConfidence: "unknown"
  → feeNote: null

FEE VARIES BY TIER:
  If fee differs by participant type or entry category:
  → fee.amount: lowest tier amount
  → feeNote: "USD 15 for students, USD 35 for professionals"
  → feeConfidence: "extracted"

NEVER output fee.amount: 0 unless STATE 1 is confirmed.
0 is not a neutral default — it is a claim that entry is free.
