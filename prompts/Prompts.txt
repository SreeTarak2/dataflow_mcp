DESCRIPTION RULES (STRICT)
==================================================

There are TWO description fields. Each serves a different purpose:

### description (short — for contest cards)
- 80–130 characters, 1–2 sentences
- Goal: "What is this and who is it for?" — instant recognition
- Neutral, informational tone. No hype, no dates, no eligibility restatement.

MANDATORY STRUCTURE — follow this order:
Sentence 1: What to submit
  Start with the submission type and any hard format constraint.
  "Submit short films under 40 minutes across any genre."
  "Submit original paintings, sculptures, or mixed media works."
  "Propose a climate-tech startup addressing food security."

Sentence 2: Who it is for
  State the audience plainly. Mirror eligibilityLabel tone.
  "Open to filmmakers worldwide."
  "For individual artists aged 18 and above."
  "For early-stage startups from African countries."

### descriptionDetailed (expanded — for contest detail page)
- 200–350 characters, 2–4 sentences
- Goal: "Why should I apply?" — motivation + key details
- Plain, conversational English. Write like a friend telling you
  about a cool opportunity.
- Avoid: showcasing, empowering, leveraging, fostering, premier,
  prestigious, renowned, world-class.

STRUCTURE:
- Start with what the contest is and what to submit (not organizer)
- Mention one meaningful detail: what makes it unique,
  what winners get, or the opportunity it unlocks
- End with a motivating hook — why someone should apply

SOURCES (derive from the page and structured data):
- `title` and `category` — context
- `prizeSummary` or `prize.description` — winner benefits
- `eligibilityLabel` / `location` — who it's for
- Unique `tags` — distinctive signals

EXAMPLE:
  description: "The world's biggest panoramic photo competition. Open to photographers everywhere."
  descriptionDetailed: "The Epson International Pano Awards is the largest competition dedicated to panoramic photography. Open to photographers at any level from nearly 100 countries, it offers cash prizes, global exposure, and the title of world's best panoramic photographer for the year."

### Banned patterns (both fields):
- Never start with the organizer name (unless genuinely famous)
- Never start with "Organized by"
- Never start with "The [Organizer] invites"
- Never describe organizer history or prestige
- Never repeat the prize amount (descriptionDetailed can mention winner benefits)
- Never repeat the deadline
- Never repeat the location
- Never use: premier, prestigious, renowned, leading,
             world-class, unique opportunity, major platform

SELF-CHECK before outputting:
1. Does sentence 1 tell the user what to submit? If not — rewrite.
2. Does sentence 2 tell the user who this is for? If not — rewrite.
3. Does any sentence mention organizer name, prestige, or history?
   If yes — delete that sentence entirely.

PRIZE RULES (EVIDENCE-BASED — ANTI-HALLUCINATION)
==================================================

⚠️ ANTI-HALLUCINATION RULE — CRITICAL

When extracting prize data from the source webpage, only the
following are VALID sources for prize amounts:
1. An explicit dollar/euro/etc. amount visibly tied to the prize
   (e.g. "€20,000 in cash prizes", "$50,000 grand prize")
2. A numbered prize tier table with amounts

The following are NOT valid sources for extracting amounts:
- General descriptions mentioning "prizes" without numbers
- Vague phrases like "amazing cash prizes", "substantial grants"
- Organizer claims about "funding" without a specific figure
- Inferring amounts from contest category or organizer reputation

If no explicit numeric amount is found on the page:
→ originalAmount = null (NOT a string with a guessed number)
→ totalUSD = null (NOT 0)
→ prizeSummary = "Cash prizes" (NOT "Cash prizes totaling $X")

==================================================

prizeSummary (REQUIRED when isMonetary = true):
- 2–10 words, human-readable string
- Card renders this directly — no conditional logic on amounts
- MUST use the exact amounts from originalAmount/totalUSD only
- Format: "Cash prizes totaling $[amount]" (with commas, e.g. "$20,000")
- If originalAmount exists (string): "Cash prizes totaling [originalAmount]"
  e.g. "Cash prizes totaling €20,000", "Cash prizes totaling NGN 5,000,000"
- If only totalUSD exists (numeric): "Cash prizes totaling $[amount]"
  Format with commas: "$20,000" not "$20000"
- If NO explicit amount found: "Cash prizes" (clean, no fabricated number)
- If non-monetary only: "Certificate + exhibition rights"
- If mixed: "Cash prizes + residency"
- NEVER leave null when isMonetary = true

originalAmount:
- TYPE IS STRING — not a number
- Capture exactly as written in source: "€20,000", "NGN 5,000,000", "$10k+"
- ONLY populate this if an explicit numeric amount was found on the page
- Do not convert — conversion is handled separately in totalUSD
- If no amount found: null

totalUSD:
- Number — USD equivalent of originalAmount
- Set to null (NOT 0) when conversion fails or amount is ambiguous
- 0 is a valid value ONLY when prize is explicitly stated as zero value
- NEVER default to 0

currency:
- ISO code: "USD", "EUR", "INR", "NGN" etc.
- null if not stated — do not default to "USD"

CLASSIFICATION (FOUR STATES — STRICT)
==================================================
Pick EXACTLY ONE state based on what the source page actually shows.
Do NOT promote to a higher state if the evidence is ambiguous.

STATE 1 — Explicit amount found:
  Source shows a specific monetary amount tied to the prize.
  → isMonetary = true
  → originalAmount = string from source (e.g. "€20,000")
  → totalUSD = numeric USD equivalent (null if conversion fails)
  → prizeSummary = "Cash prizes totaling [originalAmount]"

STATE 2 — Monetary mentioned, no amount:
  Source mentions "cash prizes", "monetary award", "prize money"
  but gives NO specific dollar/euro/etc. figure.
  → isMonetary = true
  → originalAmount = null
  → totalUSD = null (NOT 0)
  → prizeSummary = "Cash prizes"
    (No amount. Honest. The prize is monetary but the amount
    was not captured.)

STATE 3 — Only non-monetary prizes:
  Source lists prizes like certificates, exhibitions, residencies,
  publications, mentorship, etc. No cash amount mentioned.
  → isMonetary = false
  → originalAmount = null
  → totalUSD = null
  → prizeSummary = Condensed preview of actual non-monetary items
    (e.g. "Certificate + exhibition", "Residency + publication")
    Keep under 100 characters. Extract key items only.
    Do NOT copy the full description verbatim.

STATE 4 — No prize info at all:
  Source does not mention prizes of any kind (monetary or otherwise).
  → isMonetary = null
  → originalAmount = null
  → totalUSD = null
  → prizeSummary = null
  → prize.description = null (do not fill from unrelated text)

==================================================
VALIDATION CHECKLIST — FINAL VERIFICATION
==================================================
Before finalizing prize data, verify ALL of the following:

☐ Is there an actual dollar/euro/etc. amount visible on the page?
  If YES → STATE 1 + populate originalAmount from that exact text
  If NO  → Is there ANY mention of cash/monetary prizes at all?
    If YES → STATE 2 (prizeSummary = "Cash prizes")
    If NO  → Continue to non-monetary check

☐ Does the source describe non-monetary awards?
  If YES → STATE 3 (condense into 100-char summary)
  If NO  → STATE 4 (all null)

☐ Did you avoid inferring or fabricating an amount?
  Re-read your originalAmount and prizeSummary.
  Is every number there traceable to an explicit character on the page?
  If not → set to null.

ENTRY FEE RULES (FOUR STATES — STRICT)
==================================================
Pick EXACTLY ONE state. Never default fee.amount to 0.

STATE 1 — Confirmed free:
  Source explicitly says "free", "no entry fee", "free to enter",
  or "no registration fee"
  → isFree: true
  → fee.amount: 0
  → fee.currency: null
  → feeConfidence: "confirmed"
  → feeNote: null

STATE 2 — Confirmed paid, amount known:
  Source states a specific fee amount
  → isFree: false
  → fee.amount: [extracted number]
  → fee.currency: [ISO code]
  → feeConfidence: "extracted"
  → feeNote: null (or tier description if fee varies)

STATE 3 — Confirmed paid, amount unknown:
  Source mentions a fee exists but no amount is stated,
  OR fee varies by category with no extractable base amount
  → isFree: false
  → fee.amount: null
  → fee.currency: null
  → feeConfidence: "unknown"
  → feeNote: null

STATE 4 — Fee status unclear:
  Source does not mention fees at all
  → isFree: null
  → fee.amount: null
  → fee.currency: null
  → feeConfidence: "unknown"
  → feeNote: null

FEE VARIES BY TIER:
  If fee differs by participant type or entry category:
  → fee.amount: lowest tier amount
  → feeNote: "USD 15 for students, USD 35 for professionals"
  → feeConfidence: "extracted"

NEVER output fee.amount: 0 unless STATE 1 is confirmed.
0 is not a neutral default — it is a claim that entry is free.
